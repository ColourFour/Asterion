Integration of e^x and 1/x

Reverse exponential and logarithmic derivative shapes.

What to notice

Integration reverses a derivative. For $e^{kx+a}$, divide by $k$. For $f'(x)/f(x)$, use $\ln|f(x)|$ when the denominator is valid.

Log laws are only used to simplify final integral answers here. Standalone log-law work remains in Logarithmic and Exponential Functions.

Section 2 of 10

Integrals of sin, cos, and sec^2

Integrate basic trigonometric functions with linear inner functions.

What to notice

For a linear inner function, integrate the outside trig function and divide by the coefficient of $x$. Radians are the default.

These are integration rules. Trig derivative prompts remain in Differentiation and trig equation solving remains in Trigonometry.

Example 1

Keep the negative sign

Find ∫sin⁡(3x+π/4) dx\int \sin(3x+\pi/4)\,dx∫sin(3x+π/4)dx.

  2. The inner coefficient is 333, so divide by 333.
  3. ∫sin⁡(3x+π/4) dx=−13cos⁡(3x+π/4)+c\int \sin(3x+\pi/4)\,dx=-\frac13\cos(3x+\pi/4)+c∫sin(3x+π/4)dx=−31​cos(3x+π/4)+c.

Result: −13cos⁡(3x+π/4)+c -\frac13\cos(3x+\pi/4)+c −31​cos(3x+π/4)+c

Try a similar one

Find ∫cos⁡(2x) dx\int \cos(2x)\,dx∫cos(2x)dx.

  • Add c
Reveal/check the worked route

  2. The integral of cos⁡u\cos ucosu is sin⁡u\sin usinu.

Trig Identity Integrals

Rewrite trig expressions into integrable forms before evaluating.

What to notice

Some trig integrals are not direct. Use identities such as $\cos^2x=\frac12(1+\cos2x)$ and $\tan^2x=\sec^2x-1$ before integrating.

Identity work supports the integral here; pure identity proof and equation solving remain in Trigonometry.

Example 1

Use a double-angle rewrite

Find ∫cos⁡2x dx\int \cos^2x\,dx∫cos2xdx.

  2. So ∫cos⁡2x dx=12∫1 dx+12∫cos⁡2x dx\int \cos^2x\,dx=\frac12\int 1\,dx+\frac12\int \cos2x\,dx∫cos2xdx=21​∫1dx+21​∫cos2xdx.
  3. This gives x2+14sin⁡2x+c\frac{x}{2}+\frac14\sin2x+c2x​+41​sin2x+c.

Result: x2+14sin⁡2x+c \frac{x}{2}+\frac14\sin2x+c 2x​+41​sin2x+c

Try a similar one

  • Rewrite with sec^2
  • Integrate sec^2
  • Integrate 1
  • Add c
Reveal/check the worked route

Section 4 of 10

Integration With Partial Fractions

Integrate rational functions after a correct decomposition.

What to notice

Decompose first, then integrate each term. Linear denominators give logarithms; repeated factors may give reciprocal powers.

Algebra trains decomposition as algebra. Integration trains the integration after decomposition.

Example 1

Decompose before logarithms

Given 3x(x−1)(x+2)=1x−1+2x+2\frac{3x}{(x-1)(x+2)}=\frac1{x-1}+\frac2{x+2}(x−1)(x+2)3x​=x−11​+x+22​, integrate the rational function.

  1. Use the provided decomposition before integrating.
  2. ∫1x−1 dx=ln⁡∣x−1∣\int \frac1{x-1}\,dx=\ln|x-1|∫x−11​dx=ln∣x−1∣.
  3. ∫2x+2 dx=2ln⁡∣x+2∣\int \frac2{x+2}\,dx=2\ln|x+2|∫x+22​dx=2ln∣x+2∣.
  4. So the integral is ln⁡∣x−1∣+2ln⁡∣x+2∣+c\ln|x-1|+2\ln|x+2|+cln∣x−1∣+2ln∣x+2∣+c.

Result: ln⁡∣x−1∣+2ln⁡∣x+2∣+c \ln|x-1|+2\ln|x+2|+c ln∣x−1∣+2ln∣x+2∣+c

Try a similar one

Given 1x(x+1)=1x−1x+1\frac{1}{x(x+1)}=\frac1x-\frac1{x+1}x(x+1)1​=x1​−x+11​, integrate it.

  • Use decomposition
  • Integrate each linear term
  • Keep absolute values
  • Add c
Reveal/check the worked route
  1. Use the given decomposition before integrating.
  2. ∫1x dx=ln⁡∣x∣\int\frac1x\,dx=\ln|x|∫x1​dx=ln∣x∣.
  3. ∫1x+1 dx=ln⁡∣x+1∣\int\frac1{x+1}\,dx=\ln|x+1|∫x+11​dx=ln∣x+1∣.

Try result: ln⁡∣x∣−ln⁡∣x+1∣+c \ln|x|-\ln|x+1|+c ln∣x∣−ln∣x+1∣+c

Recognize and scale standard tan^{-1} integral forms.

What to notice

The standard result is $\int \frac1{1+x^2}\,dx=\tan^{-1}x+c$. Scale constants or complete the square to match that form.

The derivative of tan^{-1}x is practice. This topic assesses integral recognition and scaling.

Integration by Substitution

Change variables so the integral becomes a standard form.

What to notice

Choose $u$ so that $du/dx$ appears elsewhere in the integrand. Rewrite every part in terms of $u$ before integrating.

For definite integrals, change the limits when changing variables. For indefinite integrals, return to xxx at the end.

Example 1

Reverse chain rule as substitution

Find ∫2xx2+2 dx\int \frac{2x}{x^2+2}\,dx∫x2+22x​dx.

  1. Let u=x2+2u=x^2+2u=x2+2.
  2. Then du=2x dxdu=2x\,dxdu=2xdx, which matches the numerator and differential.
  3. The integral becomes ∫1u du=ln⁡∣u∣+c\int \frac1u\,du=\ln|u|+c∫u1​du=ln∣u∣+c.
  4. Substitute back to get ln⁡(x2+2)+c\ln(x^2+2)+cln(x2+2)+c.

Result: ln⁡(x2+2)+c \ln(x^2+2)+c ln(x2+2)+c

Try a similar one

Use u=1+exu=1+e^xu=1+ex to find ∫ex1+ex dx\int \frac{e^x}{1+e^x}\,dx∫1+exex​dx.

  • Find du
  • Rewrite the fraction
  • Integrate in u
  • Return to x
Reveal/check the worked route
  1. If u=1+exu=1+e^xu=1+ex, then du=ex dxdu=e^x\,dxdu=exdx.
  2. The integral becomes ∫1u du\int\frac1u\,du∫u1​du.
  3. Integrate and substitute back.

Try result: ln⁡∣1+ex∣+c \ln|1+e^x|+c ln∣1+ex∣+c

Improper Integral Limit Check

Replace one infinite bound by a limit before evaluating.

What to notice

Do not substitute infinity directly. Replace the infinite bound, integrate to a finite variable, then take the limit.

This is a narrow P3-style convergent improper evaluation, not a broad improper-integral course.

Example 1

Use a limit for an infinite bound

Evaluate ∫0∞e−2x dx\int_0^\infty e^{-2x}\,dx∫0∞​e−2xdx.

  2. An antiderivative is −12e−2x-\frac12e^{-2x}−21​e−2x.
  3. So [−12e−2x]0b=−12e−2b+12\left[-\frac12e^{-2x}\right]_0^b=-\frac12e^{-2b}+\frac12[−21​e−2x]0b​=−21​e−2b+21​.
  4. As b→∞b\to\inftyb→∞, e−2b→0e^{-2b}\to0e−2b→0, so the value is 12\frac1221​.

Result: 12 \frac12 21​

Try a similar one
