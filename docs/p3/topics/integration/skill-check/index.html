Find the area between y = x + 2 and y = x^2 from x = 0 to x = 2.

Key method: Area between curves is the integral of upper curve minus lower curve.

Show answer and route

Answer: 10/3

  1. On 0 <= x <= 2, the upper curve is y = x + 2 and the lower curve is y = x^2.
  2. Area is the integral of (x + 2 - x^2) from 0 to 2.
  3. An antiderivative is x^2/2 + 2x - x^3/3.
  4. Substituting 2 and 0 gives 2 + 4 - 8/3 = 10/3.

Evaluate the improper integral of e^(-2x) from x = 0 to infinity.

Key method: Replace the infinite upper bound by a limit and use the exponential limiting value.

Show answer and route

Answer: 1/2

  1. Write the integral as lim b->infinity of the integral from 0 to b of e^(-2x).
  2. An antiderivative is -(1/2)e^(-2x).
  3. Substituting 0 and b gives -(1/2)e^(-2b) + 1/2.
  4. As b tends to infinity, e^(-2b) tends to 0, so the value is 1/2.
