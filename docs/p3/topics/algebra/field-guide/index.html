Section 1 of 7

Structure Before Expansion

Choose the algebra move that preserves useful structure before expanding.

What to notice

P3 algebra often depends on seeing the repeated block, common factor, or restriction before doing mechanical expansion.

This is a P3 support bridge for structure-first manipulation. It is not a broad algebra revision page.

Example 1

Repeated block as a substitution

Solve (x2+2x)2−5(x2+2x)+6=0(x^2+2x)^2-5(x^2+2x)+6=0(x2+2x)2−5(x2+2x)+6=0 without expanding the quartic.

  1. The repeated block is x2+2xx^2+2xx2+2x, so set u=x2+2xu=x^2+2xu=x2+2x.
  2. The equation becomes u2−5u+6=0=(u−2)(u−3)u^2-5u+6=0=(u-2)(u-3)u2−5u+6=0=(u−2)(u−3).
  3. So x2+2x=2x^2+2x=2x2+2x=2 or x2+2x=3x^2+2x=3x2+2x=3.
  4. x2+2x−2=0x^2+2x-2=0x2+2x−2=0 gives x=−1±3x=-1\pm\sqrt3x=−1±3​.
  5. x2+2x−3=0x^2+2x-3=0x2+2x−3=0 gives x=1x=1x=1 or x=−3x=-3x=−3.

Result: x=−3, 1, −1−3, −1+3 x=-3,\ 1,\ -1-\sqrt3,\ -1+\sqrt3 x=−3, 1, −1−3​, −1+3​

Modulus Graphs and Equations

Treat modulus as distance, then solve with cases or graph intersections.

What to notice

A modulus output is never negative. A linear expression inside a modulus makes a V-shape because the negative side is reflected upward.

Algebra modulus here means real algebraic modulus only, not complex-number modulus or Argand diagrams.

Example 1

Equation as two graph intersections

Solve ∣x+2∣=∣3x∣|x+2|=|3x|∣x+2∣=∣3x∣ and describe the graph meaning.

  1. For ∣A∣=∣B∣|A|=|B|∣A∣=∣B∣, use A=BA=BA=B or A=−BA=-BA=−B.
  2. x+2=3xx+2=3xx+2=3x, so x=1x=1x=1.
  3. x+2=−3xx+2=-3xx+2=−3x, so x=−12x=-\frac12x=−21​.
  4. On the graph, these are the two intersections of y=∣x+2∣y=|x+2|y=∣x+2∣ and y=∣3x∣y=|3x|y=∣3x∣.

Result: x=1orx=−12 x=1\quad\text{or}\quad x=-\frac12 x=1orx=−21​

Reveal/check the worked route
  1. The equality points are x=−12x=-\frac12x=−21​ and x=1x=1x=1.

  3. For x=0x=0x=0, ∣x+2∣<∣3x∣|x+2|<|3x|∣x+2∣<∣3x∣ is false; for x=−1x=-1x=−1 and x=2x=2x=2, it is true.

Try result: x<−12orx>1 x<-\frac12\quad\text{or}\quad x>1 x<−21​orx>1

Polynomial Division

Find a quotient and remainder by long division.

What to notice

Write powers in descending order, insert zero coefficients for missing terms, and stop once the remainder has lower degree than the divisor.

Example 1

No-remainder long division

Divide x3−6x2+11x−6x^3-6x^2+11x-6x3−6x2+11x−6 by x−1x-1x−1.

  1. x3÷x=x2x^3\div x=x^2x3÷x=x2, then subtract x3−x2x^3-x^2x3−x2.
  2. The next line is −5x2+11x−6-5x^2+11x-6−5x2+11x−6.
  3. −5x2÷x=−5x-5x^2\div x=-5x−5x2÷x=−5x, then subtract −5x2+5x-5x^2+5x−5x2+5x.
  4. The next line is 6x−66x-66x−6, so add 666 and subtract 6x−66x-66x−6.
  5. The quotient is x2−5x+6x^2-5x+6x2−5x+6 and the remainder is 000.

Result: x2−5x+6remainder 0 x^2-5x+6\quad\text{remainder }0 x2−5x+6remainder 0

Remainder and Factor Theorem

Evaluate the polynomial at the divisor root.

What to notice

Treat the polynomial as a function. For divisor $x-a$, the remainder is $f(a)$; for $ax+b$, use $x=-\frac ba$.

Example 1

Use a non-monic divisor

Find the remainder when f(x)=2x3−x+4f(x)=2x^3-x+4f(x)=2x3−x+4 is divided by 2x+12x+12x+1.

  1. Set the divisor to zero: 2x+1=02x+1=02x+1=0, so x=−12x=-\frac12x=−21​.
  2. The remainder is f(−12)f\left(-\frac12\right)f(−21​).
  3. f(−12)=2(−18)−(−12)+4f\left(-\frac12\right)=2\left(-\frac18\right)-\left(-\frac12\right)+4f(−21​)=2(−81​)−(−21​)+4.
  4. So the remainder is −14+12+4=174-\frac14+\frac12+4=\frac{17}{4}−41​+21​+4=417​.

Result: 174 \frac{17}{4} 417​

Discriminant and Root Conditions

Use $b^2-4ac$ to decide root conditions before solving.

What to notice

When a question asks about real roots, repeated roots, no real roots, or tangency, the discriminant is usually the shortest route.

This bridge covers the P3 root-condition use of the discriminant only. It does not add a wider quadratic-revision curriculum.

Example 1

Repeated-root parameter

Find the values of kkk for which x2+kx+9=0x^2+kx+9=0x2+kx+9=0 has a repeated root.

  1. For ax2+bx+c=0ax^2+bx+c=0ax2+bx+c=0, the discriminant is D=b2−4acD=b^2-4acD=b2−4ac.
  2. A repeated root means D=0D=0D=0.
  3. Here a=1a=1a=1, b=kb=kb=k, and c=9c=9c=9, so k2−4(1)(9)=0k^2-4(1)(9)=0k2−4(1)(9)=0.
  4. k2−36=0k^2-36=0k2−36=0, hence k=±6k=\pm6k=±6.

Result: k=−6ork=6 k=-6\quad\text{or}\quad k=6 k=−6ork=6

Reveal/check the worked route

  2. D=(−3)2−4(2)(5)=9−40=−31D=(-3)^2-4(2)(5)=9-40=-31D=(−3)2−4(2)(5)=9−40=−31.
  3. Since D<0D<0D<0, there are no real roots.

Partial Fractions

Choose the decomposition form before solving constants.

What to notice

The denominator decides the form: distinct linear, repeated linear, or one irreducible quadratic factor.
