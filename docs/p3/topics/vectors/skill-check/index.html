  2. PQ = Q - P = <2lambda - 2, lambda - 2, 2lambda - 1>.
  3. Use perpendicularity: PQ . <2, 1, 2> = 0.
  4. This gives 2(2lambda - 2) + (lambda - 2) + 2(2lambda - 1) = 0, so 9lambda - 8 = 0.
  5. lambda = 8/9 and |PQ| = sqrt(17)/3.
