Approximation by Change of Sign

Use endpoint signs and interval narrowing to locate and round a root.

What to notice

Put the equation into $f(x)=0$, then compare signs at interval endpoints. Opposite signs show at least one root between them when $f$ is continuous.

Graph Proof of Root

Use graph intersections to prove that an equation has a root.

What to notice

Some equations can be split into two graphs. An intersection has the same $x$ and $y$ value on both graphs, so its $x$-coordinate solves the original equation.

Example 1

Explain an intersection

1. Try this first

Rearrange into $x=g(x)$ and use $x_{n+1}=g(x_n)$ to approximate a root.

Convergence of Iteration

Compare iteration formulae by their generated values and domain restrictions.

What to notice

Different rearrangements of the same equation are not equally useful. A useful iteration settles toward a root; a poor one may diverge, oscillate, or become undefined.

Example 1

Compare two rearrangements

1. Try this first

For xex=1xe^x=1xex=1, compare xn+1=e−xnx_{n+1}=e^{-x_n}xn+1​=e−xn​ and xn+1=−ln⁡(xn)x_{n+1}=-\ln(x_n)xn+1​=−ln(xn​) starting from x1=0.6x_1=0.6x1​=0.6.

2. First step

Identify same equation, then can have toward different iterations. Stop before doing the full solution.

3. Hint

First, f(0)=−1f(0)=-1f(0)=−1 and f(1)=e−1>0f(1)=e-1>0f(1)=e−1>0, so there is a root between 000 and 111.

4. Idea

Principle: Convergence check.

Show worked route
  1. First, f(0)=−1f(0)=-1f(0)=−1 and f(1)=e−1>0f(1)=e-1>0f(1)=e−1>0, so there is a root between 000 and 111.
  2. Using xn+1=e−xnx_{n+1}=e^{-x_n}xn+1​=e−xn​ gives values about 0.6,0.5488,0.5776,0.56120.6,0.5488,0.5776,0.56120.6,0.5488,0.5776,0.5612, which settle near the root.
  3. Using xn+1=−ln⁡(xn)x_{n+1}=-\ln(x_n)xn+1​=−ln(xn​) gives values that move widely, and can eventually produce a negative value.
  4. Once an iterate is negative, the next step needs ln⁡(negative)\ln(\text{negative})ln(negative), so that formula fails.

Result: xn+1=e−xnx_{n+1}=e^{-x_n}xn+1​=e−xn​ is useful here; xn+1=−ln⁡(xn)x_{n+1}=-\ln(x_n)xn+1​=−ln(xn​) may fail.

  • Look for settling
  • Check formula domain
  • State the evidence
Reveal/check the worked route
  1. The values move around but the jumps get smaller: 1.2→0.7→0.9→0.78→0.831.2\to0.7\to0.9\to0.78\to0.831.2→0.7→0.9→0.78→0.83.
