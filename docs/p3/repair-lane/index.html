Module 1 · ALGEBRA_MANIPULATION

Algebra Manipulation

Learn refresh: 10-20 min. Fast questions require at least 70%.

Learn Refresh

  1. Expand brackets first only when it makes the expression simpler. Otherwise look for a common factor.
  2. Factorise by asking: common factor, difference of two squares, then quadratic brackets.
  3. For fractions, factor before cancelling. Never cancel terms joined by plus or minus.
  4. Do: rewrite the expression. See: the shared factor or bracket. Repeat until no illegal cancellation remains.

Module 2 · EQUATION_SOLVING

Equation Solving

Learn refresh: 10-20 min. Fast questions require at least 70%.

Learn Refresh

  1. For linear equations, undo operations in reverse order and keep both sides balanced.
  2. For quadratics, first put everything on one side. Then factorise, use the formula, or spot a square.
  3. For simultaneous equations, eliminate one variable cleanly before substituting back.
  4. Do: isolate or factor. See: the operation that removes clutter. Repeat with a final substitution check.

Module 3 · TRIG_BASIC

Trigonometry Basics

Learn refresh: 10-20 min. Fast questions require at least 70%.

Learn Refresh

  1. Know the core identities: sin⁡2x+cos⁡2x=1\sin^2 x+\cos^2 x=1sin2x+cos2x=1 and tan⁡x=sin⁡xcos⁡x\tan x=\frac{\sin x}{\cos x}tanx=cosxsinx​.
  2. Use the unit circle signs: sine is y, cosine is x, tangent is sine over cosine.
  3. For exact angles, memorise 0,30,45,60,900,30,45,60,900,30,45,60,90 degrees and reflect them into other quadrants.
  4. Do: identify the quadrant. See: the sign and reference angle. Repeat before solving P3 trig equations.

Module 4 · DIFFERENTIATION_BASIC

Differentiation Basics

Learn refresh: 10-20 min. Fast questions require at least 70%.

Learn Refresh

  1. Power rule: if y=axny=ax^ny=axn, then dydx=anxn−1\frac{dy}{dx}=anx^{n-1}dxdy​=anxn−1.
  2. Differentiate each term separately. Constants disappear.
  3. Gradient questions usually need substitution after differentiating.
  4. Do: apply the power rule. See: the new coefficient and power. Repeat, then substitute the requested x-value.
