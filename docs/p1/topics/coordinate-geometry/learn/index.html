Skill 1 of 5

Form a straight-line equation

Build a line equation from a point and gradient.

Need to know

  • Use y−y1=m(x−x1)y-y_1=m(x-x_1)y−y1​=m(x−x1​).
  • Rearrange only after substituting the known point and gradient.

Common error: Substituting the point with reversed signs.

Worked example

Find the line through (2,3)(2,3)(2,3) with gradient 4.

  1. y−3=4(x−2)y-3=4(x-2)y−3=4(x−2).
  2. Expand to get y=4x−5y=4x-5y=4x−5.

Answer: y=4x−5y=4x-5y=4x−5

Skill 2 of 5

Use line forms and coordinate relationships

Use coordinate formulae and gradient relationships.

Need to know

  • Parallel lines have equal gradients.
  • Perpendicular non-vertical gradients multiply to -1.

Common error: Using the negative gradient rather than the negative reciprocal.

Worked example

Find the gradient perpendicular to a line of gradient 3.

  1. Let the new gradient be m.
  2. 3m=−13m=-13m=−1, so m=−1/3m=-1/3m=−1/3.

Answer: −1/3-1/3−1/3

Skill 3 of 5

Read and form circle equations

Read a circle centre and radius from its equation.

Need to know

  • In (x−a)2+(y−b)2=r2(x-a)^2+(y-b)^2=r^2(x−a)2+(y−b)2=r2, the centre is (a,b)(a,b)(a,b).
  • Complete both squares when converting an expanded equation.

Common error: Reading the signs inside the brackets without reversing them.

Worked example

Find the centre and radius of (x−2)2+(y+1)2=16(x-2)^2+(y+1)^2=16(x−2)2+(y+1)2=16.

  1. The bracket shifts give centre (2,−1)(2,-1)(2,−1).
  2. r2=16r^2=16r2=16, so r=4r=4r=4.

Answer: Centre (2,−1)(2,-1)(2,−1), radius 4

Skill 4 of 5

Solve line-and-circle geometry problems

Combine algebraic intersections with circle geometry.

Need to know

  • Substitute the line into the circle for intersection coordinates.
  • A tangent is perpendicular to the radius at contact.

Common error: Assuming a tangent gradient equals the radius gradient.

Worked example

A radius to a tangent point has gradient 2. Find the tangent gradient.

  1. Radius and tangent are perpendicular.
  2. 2m=−12m=-12m=−1.

Answer: m=−1/2m=-1/2m=−1/2

Skill 5 of 5

Connect graph intersections and equation roots

Translate graph contact into a root condition.

Need to know

  • Equate graph equations to form one equation.
  • Use the discriminant to distinguish crossing, touching and missing.

Common error: Applying the discriminant before reducing to one quadratic variable.

Worked example

What discriminant condition means a line touches a quadratic curve?

  1. Touching produces one shared point.
  2. The resulting quadratic has one repeated root.
