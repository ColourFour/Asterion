Skill 1 of 5

Integrate powers and simple linear composites

Reverse the power and chain rules for simple integrands.

Need to know

  • Increase a power by one and divide by the new power.
  • For (ax+b)n(ax+b)^n(ax+b)n, also divide by a.

Common error: Forgetting the coefficient from the inner linear expression.

Worked example

Integrate 6(2x+1)26(2x+1)^26(2x+1)2.

  1. Increase the power to 3.
  2. Divide by 2×32\times32×3, which cancels the factor 6.

Answer: (2x+1)3+C(2x+1)^3+C(2x+1)3+C

Skill 2 of 5

Determine a constant of integration

Use a known point to finish an indefinite integration problem.

Need to know

  • Write +C before applying the condition.
  • Substitute both coordinates into the general equation.

Common error: Dropping the integration constant before using the given point.

Worked example

Given dy/dx=2xdy/dx=2xdy/dx=2x and y=5 when x=2, find y.

  1. y=x2+Cy=x^2+Cy=x2+C.
  2. 5=4+C5=4+C5=4+C, so C=1C=1C=1.

Answer: y=x2+1y=x^2+1y=x2+1

Evaluate definite and simple improper integrals

Evaluate an antiderivative at two bounds in the correct order.

Need to know

  • Use F(b)−F(a)F(b)-F(a)F(b)−F(a).
  • For an allowed improper endpoint, use the limiting value indicated by the expression.

Common error: Subtracting upper from lower or omitting brackets around a negative value.

Worked example

Evaluate ∫132x dx\int_1^3 2x\,dx∫13​2xdx.

  1. An antiderivative is x2x^2x2.
  2. 32−12=83^2-1^2=832−12=8.

Skill 4 of 5

Find bounded areas with definite integration

Build a non-negative geometric area from definite integrals.

Need to know

  • Use upper curve minus lower curve.
  • Split where the order changes or a graph crosses the axis.

Common error: Accepting a negative definite integral as a negative area.

Worked example

Find the area under y=xy=xy=x from x=0 to x=2.

  1. ∫02x dx=[x2/2]02\int_0^2x\,dx=[x^2/2]_0^2∫02​xdx=[x2/2]02​.
  2. The result is 2.

Answer: 2 square units
