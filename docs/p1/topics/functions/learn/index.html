Skill 1 of 10

Determine a function domain

Distinguish permitted inputs from produced outputs.

Need to know

  • The domain is the set of allowed inputs.
  • The range is the set of values the function actually outputs.

Common error: Giving the domain when the question asks for the range.

Worked example

Find the domain of f(x)=1/(x+2)f(x)=1/(x+2)f(x)=1/(x+2).

  1. The denominator must be non-zero.
  2. x+2≠0x+2\ne0x+2=0, so x≠−2x\ne-2x=−2.

Answer: R∖{−2}\mathbb{R}\setminus\{-2\}R∖{−2}

Skill 2 of 10

Determine a function range

Determine the complete set of possible outputs.

Need to know

  • Use the graph shape or an algebraic bound.
  • Apply any stated input-domain restriction before giving the range.

Common error: Repeating the domain instead of finding output values.

Worked example

Find the range of f(x)=(x−2)2+3f(x)=(x-2)^2+3f(x)=(x−2)2+3 for real x.

  1. A square is non-negative.
  2. The least output is therefore 3.

Answer: [3,∞)[3,\infty)[3,∞)

Skill 3 of 10

Calculate a composite function

Apply the inner function first and preserve validity.

Need to know

  • gf(x)gf(x)gf(x) means g(f(x))g(f(x))g(f(x)).
  • The range of f must lie inside the domain of g.

Common error: Reversing the order of a composite function.

Worked example

For f(x)=x+2f(x)=x+2f(x)=x+2 and g(x)=x2g(x)=x^2g(x)=x2, find gf(x)gf(x)gf(x).

  1. Apply f first: f(x)=x+2f(x)=x+2f(x)=x+2.
  2. Then square: g(f(x))=(x+2)2g(f(x))=(x+2)^2g(f(x))=(x+2)2.

Answer: (x+2)2(x+2)^2(x+2)2

Skill 5 of 10

Test one-one behaviour and choose a valid restriction

Confirm one-one behaviour before reversing a function.

Need to know

  • A one-one function gives no output from two different permitted inputs.
  • Write y=f(x), swap x and y, then rearrange.

Common error: Writing an inverse for a many-to-one function without restricting its domain.

Worked example

Explain why f(x)=x2f(x)=x^2f(x)=x2 is not one-one for all real x.

  1. f(2)=4f(2)=4f(2)=4 and f(−2)=4f(-2)=4f(−2)=4.
  2. Two permitted inputs produce the same output.

Answer: It is many-one on the real numbers

Find an inverse-function formula

Reverse a one-one function algebraically.

Need to know

  • Write y=f(x) and make x the subject.
  • Swap the input-output labels only after rearranging.

Skill 7 of 10

Map points between a function and its inverse

Reflect a one-one function graph across y=x.

Need to know

  • Every point (a,b)(a,b)(a,b) becomes (b,a)(b,a)(b,a).
  • The domain and range exchange roles.

Common error: Reflecting in an axis instead of in the line y=x.

Worked example

A graph of f contains (2,5)(2,5)(2,5). Give the corresponding point on f−1f^{-1}f−1.

  1. Inverse functions swap inputs and outputs.
  2. Swap the coordinates.

Answer: (5,2)(5,2)(5,2)

Skill 8 of 10

Sketch an inverse graph by reflection

Produce a complete inverse graph by reflection in y=x.

Need to know

  • Swap the coordinates of every key point.
  • Reflect endpoints, intercepts and asymptotes, not just the curve shape.

Common error: Reflecting in an axis or sketching an unrestricted many-one inverse.

Worked example

Describe how to sketch the inverse of a one-one graph through (0,2)(0,2)(0,2) and (3,5)(3,5)(3,5).

  1. Draw the mirror line y=xy=xy=x.
  2. Transfer the key points to (2,0)(2,0)(2,0) and (5,3)(5,3)(5,3) and reflect the connecting shape.

Answer: A reflection of the permitted graph in y=xy=xy=x

Skill 9 of 10

Apply graph stretches

Predict a graph transformation from its algebraic form.

Need to know

  • Changes outside f act directly on y-values.
  • Changes inside f act oppositely on x-location and may rescale horizontally.

Common error: Moving f(x+a)f(x+a)f(x+a) right instead of left.

Worked example

Describe the change from y=f(x)y=f(x)y=f(x) to y=3f(x)y=3f(x)y=3f(x).

  1. Every output value is multiplied by 3.
  2. Horizontal positions are unchanged.

Answer: Vertical stretch factor 3
